# Triage labels

| Canonical role | Tracker label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待评估 |
| needs-info | needs-info | 待补充信息 |
| ready-for-agent | ready-for-agent | 规格与验收已明确，可由 agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不处理 |

在本仓 issue-tracker.md 指定的任务仓应用这些标签。标签表示任务分类，不代替执行授权、共享资源协调或验收证据。
